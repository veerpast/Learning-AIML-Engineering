# Learning AI/ML Engineering

This repository is an evolving, production-minded workspace documenting my hands-on progress in AI/ML engineering. It records what I am actively building and learning, while keeping future topics clearly separate from completed work.

## Current Focus

- Strengthening Python foundations for AI-oriented development.
- Building and testing a privacy-aware face-detection and anonymization application with a FastAPI backend and React frontend.
- Practising reproducible setup, dependency management, testing, containerization, and deployment configuration.

## Learning Progress

Current work covers Python exercises and an applied face-detection project using backend APIs, multiple detector implementations, anonymization, benchmarking, tests, a web interface, notebooks, and deployment configuration.

The intended progression is Python; data work and SQL; machine learning; FastAPI and backend engineering; PyTorch and deep learning; MLOps; transformers; retrieval-augmented generation (RAG); LLM engineering; and full-stack deployment. Topics in this progression are goals, not claims of completion unless corresponding work appears in the repository.

## Repository Structure

- `Python/` — current Python learning exercises and editor configuration.
- `FaceDetection/` — the current face-detection and anonymization project, including backend source and tests, frontend source and assets, an exploration notebook, scripts, and runtime/deployment configuration.

Local environments, installed dependencies, generated builds, model weights, caches, and manual test inputs are intentionally excluded from version control.

## Engineering Practices

- Keep commits small and tied to genuine daily progress.
- Separate source and configuration from generated artifacts and local dependencies.
- Keep secrets, credentials, private data, datasets, and model weights out of Git.
- Add tests and documentation alongside meaningful implementation changes.
- Prefer reproducible dependency and deployment configuration over machine-specific state.
